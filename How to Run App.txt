HOW TO RUN CATECHISMAPP
========================

You need TWO things running at the same time: the API server, and the web app.

STEP 1 — Start the API server
------------------------------
1. Open a terminal in VS Code (Terminal > New Terminal)
2. Navigate into the api folder:
   cd api
3. Install dependencies (only needed the first time, or on a new computer):
   npm install
4. Start the server:
   node server.js
5. Confirm you see this message:
   API server running at http://localhost:3000
6. Leave this terminal open and running the whole time you're using the app.

STEP 2 — Start the web app
----------------------------
1. In VS Code's file explorer, right-click index.html
2. Click "Open with Live Server"
3. Your browser should open automatically to the app's login screen.

STEP 3 — Use the app
----------------------
1. Enter your name, click Continue (or press Enter)
2. You should see today's real feast day appear under "New"
3. Click "Start Lessons" to go to the lesson path

TROUBLESHOOTING
----------------
- If the feast day shows "Feast day unavailable," the API server
  (Step 1) probably isn't running, check that terminal first.
- If a button does nothing, open the browser console (F12 > Console tab) and look for a red error message.
- If you stop and restart later, you must repeat BOTH Step 1 and Step 2, closing VS Code or your browser stops the API server too.
